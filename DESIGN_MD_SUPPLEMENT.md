### 1.2.1 儿童健康保护机制
```
┌────────────────────────────────────────────────────────────────────┐
│                    系统级保护（不可关闭）                            │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│  ⏰ 每日任务比例要求（系统自动校验）                                  │
│  ┌────────────────────────────────────────────────────────────┐   │
│  │  📅 平时（周一~周五）                                        │   │
│  │  ├─ 学习任务：最多 3 个                                      │   │
│  │  ├─ 运动项目：至少 1 个（硬性要求）                          │   │
│  │  ├─ 娱乐/休息：0-1 个                                       │   │
│  │  └─ 总计：3-4 个任务                                        │   │
│  │                                                             │   │
│  │  🏖️ 周末/节假日                                             │   │
│  │  ├─ 学习任务：最多 4 个                                      │   │
│  │  ├─ 运动项目：至少 1 个（硬性要求）                          │   │
│  │  ├─ 娱乐项目：至少 1 个                                      │   │
│  │  └─ 总计：5-6 个任务                                        │   │
│  └────────────────────────────────────────────────────────────┘   │
│                                                                    │
│  ⚠️ 违规拦截机制：                                                  │
│  ├─ 家长添加第4个学习任务时 → 系统提示"平时建议不超过3个学习任务"     │
│  ├─ 未添加运动任务就设置学习任务 → 系统禁止保存，提示"需先添加运动"  │
│  ├─ 周末未添加娱乐任务 → 系统提示"建议安排娱乐时间"                 │
│  └─ 家长可选择"强制确认"跳过提示（用于特殊情况）                    │
│                                                                    │
│  🛋️ 强制休息提醒                                                   │
│  ├─ 连续完成 ≥2 个任务 → 强制显示"休息一下"动画                    │
│  └─ 任务间建议休息时间：15分钟                                     │
│                                                                    │
│  🌙 夜间锁定模式                                                   │
│  ├─ 默认21:00-7:00 游戏功能锁定                                    │
│  └─ 仅显示"小火龙睡着了，明天再见"                                  │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

### 1.2.2 任务类型定义
```
┌────────────────────────────────────────────────────────────────────┐
│                    任务分类说明                                      │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│  📚 学习类任务（周一~周五最多3个，周末最多4个）                        │
│  ├─ 完成作业（含各学科）                                            │
│  ├─ 复习/预习                                                      │
│  ├─ 阅读/练字                                                      │
│  ├─ 练习乐器/画画                                                  │
│  └─ 其他学业相关                                                   │
│                                                                    │
│  🏃 运动类任务（每天至少1个）                                       │
│  ├─ 户外运动（跑步、骑车、踢球等）                                   │
│  ├─ 室内运动（跳绳、体操、跳舞等）                                   │
│  ├─ 体育课                                                          │
│  └─ 眼保健操/远眺放松                                              │
│                                                                    │
│  🎮 娱乐类任务                                                     │
│  ├─ 玩游戏（益智类）                                                │
│  ├─ 看动画/纪录片                                                   │
│  ├─ 自由玩耍/创意活动                                               │
│  ├─ 亲子互动游戏                                                    │
│  └─ 户外探索/亲近自然                                               │
│                                                                    │
│  🏠 家务类任务（灵活计入，非学习即满足要求）                          │
│  ├─ 整理房间/叠衣服                                                │
│  ├─ 帮忙洗碗/倒垃圾                                                │
│  └─ 照顾植物/宠物                                                  │
│                                                                    │
│  ⭐ 习惯类任务（非强制但建议）                                       │
│  ├─ 早起/早睡                                                      │
│  ├─ 自己穿衣洗漱                                                    │
│  └─ 饭前洗手/整理物品                                              │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
