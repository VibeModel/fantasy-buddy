# 《奇幻小伙伴》UI设计方案

## 📱 界面总览

### 儿童端界面列表
| 界面名称 | 功能描述 |
|---------|---------|
| 1. 启动页 | Logo + 开始按钮 |
| 2. 角色选择页 | 选择我的角色（小朋友） |
| 3. 设备配对页 | 显示设备码，等待爸妈绑定 |
| 4. 主界面 | 宠物展示 + 任务入口 + 材料背包 |
| 5. 宠物详情页 | 查看宠物状态，喂食/玩耍/洗澡 |
| 6. 任务列表页 | 今日任务清单 |
| 7. 任务完成页 | 完成任务，生成验证码 |
| 8. 验证等待页 | 显示验证码，等待爸妈验证 |
| 9. 奖励领取页 | 领取奖励，动画反馈 |
| 10. 材料背包页 | 查看所有材料 |
| 11. 成就页 | 查看已获得成就 |
| 12. 睡眠模式页 | 夜间锁定显示 |

### 家长端界面列表
> 本地单机版：家长端无需注册/登录，从启动页直接进入主控制台。

| 界面名称 | 功能描述 |
|---------|---------|
| 1. 启动页 | Logo + 选择儿童端 / 家长端 |
| 2. 主控制台 | 待验证任务 + 孩子状态总览 |
| 3. 任务验证页 | 输入验证码 / 审批密码确认任务 |
| 4. 添加/编辑任务页 | 添加任务、模板快选与奖励设置 |
| 5. 每日任务计划页 | 管理每日任务计划 |
| 6. 孩子报告页 | 查看周报/月报统计 |
| 7. 系统设置页 | 游戏时长、审批密码、通知设置 |

## 🎨 UI 设计规范

### 配色方案
| 用途 | 颜色 | 色值 |
|-----|------|-----|
| 主色 | 温暖橙 | #FF8A65 |
| 辅助色 | 梦幻紫 | #B388FF |
| 成功色 | 草地绿 | #69F0AE |
| 警告色 | 太阳黄 | #FFD54F |
| 背景色 | 软蓝白 | #F5F7FA |
| 文字色 | 深灰 | #333333 |

### 字体规范
- 标题：圆体，18-22sp，加粗
- 正文：圆体，14-16sp
- 按钮：圆体，16sp，加粗
- 数字：等宽字体，便于阅读验证码

### 圆角规范
- 卡片：16px 圆角
- 按钮：24px 圆角
- 输入框：12px 圆角
- 小标签：8px 圆角

### 动画规范
- 页面切换：300ms 淡入淡出
- 按钮点击：100ms 缩放动画
- 奖励获得：500ms 弹出 + 金币飞散
- 宠物动作：循环呼吸动画
- 验证码显示：200ms 逐字出现
